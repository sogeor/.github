# .github

> Default community health files and organization profile for sogeor.

GitHub uses these files for every repository in the [sogeor](https://github.com/sogeor) organization that does not have its own copy: Code of Conduct, contributing guidelines, security policy, support, CLA, issue forms and the pull request template. `profile/README.md` is shown on the organization page.

## Install

Nothing to install. GitHub applies the files automatically.

## Usage

Edit a file here to change it for all repositories. A repository overrides a file by adding its own copy.
