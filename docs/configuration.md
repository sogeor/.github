# Configuration

This repository has no runtime options. What can be configured is which files exist, how GitHub
inherits them, and the settings of the checks.

## Inherited defaults

| File | Inherited by repositories without their own | Notes |
|---|---|---|
| `SECURITY.md` | yes | Shown in **Security → Policy** |
| `CONTRIBUTING.md` | yes | Linked when opening issues and pull requests |
| `CODE_OF_CONDUCT.md` | yes | Shown in **Insights → Community Standards** |
| `GOVERNANCE.md` | yes | |
| `SUPPORT.md` | yes | Linked when opening issues |
| `.github/ISSUE_TEMPLATE/` | yes, as a whole | A repository with any own issue template gets none of these |
| `.github/PULL_REQUEST_TEMPLATE.md` | yes | |
| `profile/README.md` | organization page only | |
| `LICENSE`, `CODEOWNERS`, workflows, linter configuration, `renovate.json` | no | Apply to this repository only |

A repository file of the same type in its root, `.github/` or `docs/` replaces the default entirely;
files are not merged.

## Issue templates

| File | Key | Value | Description |
|---|---|---|---|
| `config.yml` | `blank_issues_enabled` | `false` | Issues must use a form |
| `config.yml` | `contact_links[0]` | Report a vulnerability | Points to `SECURITY.md` instead of a public issue |
| `bug_report.yml` | `labels` | `[bug]` | Required fields: what happened, expected behavior, steps to reproduce; optional: version |
| `feature_request.yml` | `labels` | `[enhancement]` | Required fields: problem, proposal; optional: alternatives |

## Workflows

| Workflow | Job (status check) | Triggers | Permissions | Secrets |
|---|---|---|---|---|
| `validate.yml` | `linters` | pull request, push to `master`, manual | `contents: read` | none |
| `docs.yml` | `docs` | pull request, push to `master`, manual | `contents: read` | none (uses `github.token` for lychee) |
| `scorecard.yml` | `Scorecard analysis` | push to `master`, weekly, branch protection changes | `security-events: write`, `id-token: write`, read for the rest | `SCORECARD_TOKEN` |

`validate` runs yamllint, actionlint, zizmor and gitleaks. `docs` runs markdownlint, lychee
(links to issue forms and security advisories are excluded because they require sign-in) and
`mkdocs build --strict`.

## Secrets

| Name | Type | Required | Source |
|---|---|---|---|
| `SCORECARD_TOKEN` | repository secret | yes, for `scorecard.yml` | Fine-grained PAT, Administration: Read-only, this repository only, 1 year ([Setup](setup.md#6-repository-secret-for-scorecard)) |

## Linter configuration

| File | Purpose |
|---|---|
| `.pre-commit-config.yaml` | Local hooks: whitespace and YAML checks, private keys, gitleaks, yamllint, markdownlint, actionlint, zizmor; every hook pinned by SHA |
| `.yamllint` | `extends: default`, line length 160, `true`/`false` only, no document start |
| `.markdownlint.yaml` | Default rules except line length (MD013) and table column style (MD060); fenced code blocks |
| `.github/requirements-*.in` | Top-level Python tools; `*.txt` are generated by `pip-compile --generate-hashes` |
| `renovate.json` | Monthly updates of actions, pre-commit hooks and Python tools; no automerge |

## Per-repository files

Every sogeor repository has, in addition to inherited defaults: `README.md`, `CHANGELOG.md`,
`ROADMAP.md`, `LICENSE` (Apache-2.0), `.gitignore`, `.gitattributes`, `.editorconfig`,
`.pre-commit-config.yaml`, `.markdownlint.yaml`, `renovate.json`, `.github/CODEOWNERS`,
`.github/workflows/{validate,docs,scorecard}.yml`, `mkdocs.yml` and `docs/`.
