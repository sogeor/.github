# Support

This is the default support policy for all [sogeor](https://github.com/sogeor) repositories.

| You have | Go to |
|---|---|
| A question about how something works | The repository's `docs/` directory, then an issue in that repository |
| A bug | An issue in the affected repository (**Issues → New issue → Bug report**) |
| A feature idea | An issue in the affected repository (**Issues → New issue → Feature request**) |
| A vulnerability | Private Vulnerability Reporting per [SECURITY.md](SECURITY.md); never a public issue |
| A conduct concern | The maintainer, per [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

Issues are accepted in English or Russian. The project has a single maintainer and no guaranteed
response time for questions and features; vulnerability reports follow the timelines in
[SECURITY.md](SECURITY.md).
