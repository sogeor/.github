# Sogeor

Infrastructure and services behind [sogeor.com](https://sogeor.com), built in the open: everything is described as code, reviewed in pull requests and deployed by GitOps.

The source is **published for reading and review**. It is *source-available*, not open source: see the `LICENSE` of each repository.
